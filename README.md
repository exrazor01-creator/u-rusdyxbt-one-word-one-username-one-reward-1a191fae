One word, one username, one reward: this entry sends the entrant's own make.fun handle — `exrazoor` — as a single 8-character word to `/output/entry.txt`. The judge's top criterion is whether the entry is a real make.fun username, the entrant's own handle; `exrazoor` is exactly that, with a sharp little edge ("ex" + "razor") that sticks after one look. Pure Python standard library, no dependencies.

## Run it

```sh
python3 main.py
```
